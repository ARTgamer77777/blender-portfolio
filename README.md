# Still Learning — Blender portfolio

A small, responsive portfolio for a beginner learning Blender. It uses two supplied renders and describes the work honestly: the scenes were assembled from free models, with practice focused on lighting, composition, reflections, and atmosphere.

## Preview locally

Open `index.html` in a browser. The page is static and has no build step or dependencies. Google Fonts are optional; system fonts are used as fallbacks.

## Files

- `index.html` — page content and accessible scene viewer
- `styles.css` — responsive visual design
- `script.js` — image viewer and current year
- `assets/` — the two portfolio renders supplied for this site

Before publishing, add the original model creators and source links if the free models' licenses require attribution.
